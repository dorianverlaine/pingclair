Linux HTTP/3 interop — independent client against the Linux release binary
=========================================================================

Server : /target/release/pingclair (built in rust:1.88-bookworm, linux/arm64)
         config: internal CA, http3 true, listen 0.0.0.0:8443
Client : docker ymuski/curl-http3 (linux/amd64 under emulation)
         curl 8.2.1-DEV BoringSSL nghttp2/1.52.0 quiche/0.18.0

Note the client links quiche 0.18.0 while Pingclair links quiche 0.29.3, so
this is genuinely cross-version interop, not our implementation agreeing with
itself.

  server=192.168.117.2
  $ curl --http3-only --resolve h3.local:8443:$IP https://h3.local:8443/ready
  ready
  $ curl --http3-only -w 'http_version=%{http_version}\n' ... /who
  http_version=3
  $ curl --http3-only ... /who
  linux-h3
